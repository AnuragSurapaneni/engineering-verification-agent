# Engineering Verification Agent

This project develops an Engineering Verification Agent.

The objective is to verify engineering calculations rather than simply generate answers.

The system should prioritize:

- dimensional consistency
- explicit assumptions
- independent numerical calculations
- unit consistency
- authoritative references
- physical sanity checks
- reproducibility
- automated testing

The system must not claim that an engineering result has been verified when the available information is insufficient.

When uncertainty exists, explicitly report it.
